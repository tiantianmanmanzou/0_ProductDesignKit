# 全局约束

## 1. 列表驱动设计

- 页面以列表为主体，所有操作围绕列表展开
- 页面级操作（新增、导入、批量）在列表上方，行级操作（编辑、删除、详情）在列表内部
- CRUD操作完成后自动刷新列表，形成闭环
- 基于数据状态和用户权限控制按钮显隐

## 2. 信息呈现原则

- **精简优先**：用短句/关键词代替长段落，复杂信息放入表格
- **不重复**：同一字段规格只在一处定义（字段字典），其他地方引用即可
- **两张核心表**：每个页面/弹窗的信息通过 `字段字典` + `交互矩阵` 两表承载，页面功能分区用3-5条短句概括在交互矩阵前，按钮操作、分页、排序等交互一律写入交互矩阵，不单独成表

## 3. 流程完整性

- 覆盖主流程、异常流程（权限不足、数据为空、校验失败、并发冲突）
- 明确状态定义与流转规则
- 处理边界：首次使用、极限数据量、空状态

### 页面布局规则

- 页面左右两侧对齐，边框宽度统一

- 列表表头与数据列垂直对齐，表格包含2-3行样例数据
- 样例数据每列宽度不超过15字符，超出用 `...` 截断
- 分页栏置于列表右下方，格式：`每页[20▼] 共[N]条 < 1 2 3 ... >`

### 列表列对齐方法

ASCII布局图中列表需竖直对齐，但中文字符在等宽字体中占2个英文字符宽度，直接用空格补齐会导致错位。对齐步骤如下：

1. **确定每列目标显示宽度**：根据表头和各数据行的最长内容，设定每列的"显示宽度"（目标值需 ≥ 该列所有单元格的显示宽度）
2. **计算每个单元格的显示宽度**：使用 `unicodedata.east_asian_width()`，将 W(宽)、F(全角)、A(暧昧) 计2，其余计1。⚠ `▼◀▶▲▼○●×` 等符号的 East_Asian_Width 为 A，在 CJK 环境下占2宽度，不可按1处理
3. **用空格补齐到目标宽度**：每个单元格内容右侧补 `目标宽度 - 当前显示宽度` 个空格
4. **验证整行总显示宽度一致**：所有行的 `| 内容 | 内容 | ... |` 总显示宽度必须相同，否则 `|` 位置偏移

示例（Python伪代码）：

```python
import unicodedata

def display_width(s):
    """计算字符串在CJK等宽终端中的显示宽度"""
    w = 0
    for ch in s:
        if unicodedata.east_asian_width(ch) in ('W', 'F', 'A'):
            w += 2
        else:
            w += 1
    return w

def pad_to_width(s, target_width):
    """用空格将字符串右侧补齐到目标显示宽度"""
    return s + ' ' * (target_width - display_width(s))

# 设定各列目标显示宽度
col_widths = [14, 16, 12, 10, 14, 8, 20]
# 生成对齐行
line = '| ' + ' | '.join(pad_to_width(cell, w) for cell, w in zip(row, col_widths)) + ' |'
```

**注意事项**：
- 列宽目标值必须大于等于该列所有单元格（含表头和数据行）的显示宽度，否则超长内容会破坏对齐
- 外框宽度 = 各列显示宽度之和 + 列数×3（` | `占3字符） + 1（首 `|`），所有行（边框、内容、分隔线）总显示宽度须一致
- 样例数据每列宽度建议不超过15字符（含中文字符按2计），超出用 `...` 截断
- ⚠ **避免在右对齐位置使用 Ambiguous 字符**：`×▼○●` 等 East_Asian_Width=A 的符号在不同编辑器/字体下渲染宽度不一致（1或2），破坏对齐。关闭按钮 `[x]` 替代 `[×]`，单选 `(*)/(o)` 替代 `(●)/(○)`，勾选 `[x]/[ ]` 替代 `[☑]/[☐]`。页面内 `[全部▼]` 等左侧控件不受右对齐影响可保留

### ASCII绘制符号

- 输入框 `[____]`，下拉选择 `[选项▼]`，按钮 `[确认]`，单选 `(*)` / `(o)`，勾选 `[x]` / `[ ]`
- 表单布局图中的必填字段须在字段名前加 `*` 标记，必填范围以字段字典的"必填校验"列为准；`是`、`必填`、`新增必填`、`变更必填`、`删除必填`、`变更/删除必选` 等条件必填字段均需标记。格式示例：`*工单名称[____]`、`*归属部门[选项▼]`
- 用 `+` `-` `|` 绘制边框，`=` 分隔表头，`-` 分隔表头与数据行
- 弹窗右上角放置 `[x]` 关闭按钮（ASCII 替代 Ambiguous 字符，避免右侧竖线错位）
